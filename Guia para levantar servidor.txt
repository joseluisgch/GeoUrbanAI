REcomendacion es generar un entorno virtual y usar un editor:

:: 1. Entrar a la carpeta del backend
cd ruta\a\geovisor-ia\backend

:: 2. Crear el entorno virtual
python -m venv .venv

:: 3. Activarlo (CMD)
.venv\Scripts\activate

:: Si usas PowerShell en VSCode:
:: .venv\Scripts\Activate.ps1

:: 4. Instalar dependencias
pip install -r requirements.txt

:: 5. Setear la API key de Groq (solo dura mientras el CMD esté abierto)
set GROQ_API_KEY=tu_api_key_aqui

:: 6. Levantar el servidor
uvicorn main:app --reload --port 8000
